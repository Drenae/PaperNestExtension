# Développement de PaperNestExtension

PaperNestExtension regroupe les contrôles Flet personnalisés nécessaires à PaperNest.

## Philosophie

- L’extension existe uniquement pour répondre aux besoins réels de PaperNest.
- Aucun contrôle ne doit être ajouté « au cas où ».
- Chaque contrôle doit avoir une API Python cohérente, une implémentation Flutter maintenable et un exemple fonctionnel.
- Les roadmaps et le changelog font partie intégrante du développement.

## Organisation de la documentation

- `RULES.md` : règles obligatoires de développement.
- `CHANGELOG.md` : historique des évolutions importantes.
- `roadmaps/ROADMAP_CONTROLS.md` : état global des contrôles.
- `roadmaps/ROADMAP_<CONTROL>.md` : suivi détaillé d’un contrôle en cours.
